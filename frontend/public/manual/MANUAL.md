# DN.GG 사용 가이드

농구 경기 기록·통계 서비스 **DN.GG** 사용 방법을 안내합니다.

---

## 시작 전: 그룹 선택

앱에 접속하면 제일 먼저 **오른쪽 상단의 그룹 선택**을 해야 합니다.  
그룹을 선택해야 경기 기록, 랭킹 등 모든 데이터가 표시됩니다.

![그룹 선택](screenshots/ann-01-home.png)

오른쪽 상단 드롭다운에서 내 그룹을 선택하세요.

> 그룹에 기록된 게임이 아직 없다면 홈 화면에 **시작 가이드 체크리스트**가 표시됩니다.
> 로그인 → 그룹 선택 → 팀 구성 → 게임 생성 → 기록 순서를 따라가면 됩니다.

---

## 1. 홈 — 경기 요약

그룹을 선택하면 홈 화면에 **지금까지 진행한 경기 목록**이 표시됩니다.

![경기 요약](screenshots/01-home-with-group.png)

- 각 경기 카드에서 **날짜, 팀명, 최종 점수(승·패)** 를 확인할 수 있습니다.
- **선수 이름**을 클릭하면 그 선수의 전체 기록 페이지로 이동합니다.
- 진행 중인 경기가 있으면 상단에 **"진행 중인 경기 N건 — 이어서 기록하기"** 배너가 표시됩니다.

---

## 2. 경기 만들기 (`games`)

상단 메뉴의 **games** 를 클릭합니다.

> 이 메뉴는 로그인 전에는 🔒 자물쇠로 표시됩니다.
> **로그인하고 내 소속 그룹을 선택하면** 잠금이 풀립니다.

![게임 관리](screenshots/ann-02-games.png)

### 새 경기 만들기

1. 오른쪽 상단 **새 게임 생성** 버튼을 클릭합니다.

![게임 생성 모달](screenshots/ann-02-games-modal.png)

2. **① Home팀**, **② Away팀**을 각각 선택합니다.  
   (팀이 없으면 모달이 **팀 관리로 이동** 버튼을 안내합니다 → [3번 참고](#3-팀-선수-관리-teams))
3. **③ 생성** 버튼을 누르면 경기가 시작됩니다.

### 경기 관리

| 버튼 | 설명 |
|------|------|
| 경기 카드 클릭 | 실시간 기록 화면으로 이동 |
| **게임 종료** | 경기를 완료 처리 (확인 창이 뜹니다) |
| **다시 진행하기** | 완료된 경기를 다시 진행 중으로 변경 |
| **삭제** | 경기 삭제 (복구 불가 — 빨간 확인 창이 뜹니다) |

---

## 3. 팀·선수 관리 (`teams`)

상단 메뉴의 **teams** 를 클릭합니다. (games와 마찬가지로 로그인 후 이용 가능)

![팀 관리](screenshots/ann-03-teams.png)

### 선수 추가하기

1. **① 선수 추가** 버튼을 클릭합니다.
2. 이름과 등번호를 입력하고 저장합니다.

### 선수 수정·삭제하기

- 선수 카드 오른쪽의 **⋯ 버튼**을 누르면 수정/삭제 창이 열립니다.
- 선수 카드를 **길게 누르기(0.5초)** 해도 같은 창이 열립니다.

### 팀 만들기

1. **② 팀 추가** 버튼을 클릭하고 팀 이름을 입력합니다.
2. **선수 목록**에서 선수를 클릭해 선택한 뒤, 팀의 **선수 추가** 버튼으로 배정합니다.
3. 팀 구성을 처음부터 다시 하려면 **③ 팀 구성 초기화**를 클릭합니다. (선수 명단은 유지됩니다)

---

## 4. 실시간 경기 기록 (`record`)

진행 중인 경기 카드를 클릭하면 기록 화면으로 이동합니다.
처음 방문하면 **기록 방법 안내**가 자동으로 표시됩니다.

> 기록 입력은 **로그인이 필요**합니다. 비로그인 상태에서는 조회만 가능합니다.

![경기 기록](screenshots/ann-07-record.png)

| 번호 | 버튼 | 설명 |
|------|------|------|
| ① | **뒤로 가기** | 경기 목록으로 돌아가기 |
| ② | **팀 위치 바꾸기** | 홈·어웨이팀 좌우 위치 전환 |
| ③ | **↩ 되돌리기** | 방금 입력한 기록 취소 (취소된 내용이 하단에 표시됩니다) |
| ④⑤ | **선수 버튼** | 클릭 → 기록 항목 선택 (득점·어시·리바 등) |

### 기록 입력 순서

1. 기록할 **선수 버튼**을 클릭합니다.
2. 화면이 바뀌면 **기록 항목**을 선택합니다 (2점, 3점, 어시, 리바운드 등).
3. 중앙 피드에 기록이 추가되고 **점수가 자동으로 계산**됩니다.
4. 잘못 입력했으면 **↩ 되돌리기**로 취소합니다.

> 💡 **가로 모드를 권장**하지만, 세로 모드에서도 기록할 수 있습니다.
> 선수 버튼의 빨간 배지는 해당 선수의 **파울 수**입니다.

---

## 5. 일일 기록 (`daily`)

상단 메뉴의 **daily** 를 클릭합니다.

![일일 기록](screenshots/ann-04-daily.png)

- **① 날짜 드롭다운**에서 원하는 날짜를 선택하면  
  그날 진행된 모든 경기의 **선수별 스탯 합계**를 표로 확인할 수 있습니다.

---

## 6. 랭킹 (`rankings`)

상단 메뉴의 **rankings** 를 클릭합니다.

![랭킹](screenshots/ann-05-rankings.png)

- **① 전체 기록** 탭: 시즌 누적 합산 순위
- **② 게임당 평균** 탭: 경기당 평균 순위
- **③ 카테고리 제목** 클릭: 해당 항목 접기/펼치기

득점 · 어시 · 리바 · 스틸 · 블록 · 턴오버 · 파울 · 3점 · 2점 카테고리별 **상위 3명**을 확인할 수 있습니다.

---

## 7. 선수 기록 조회

홈 화면에서 **선수 이름을 클릭**하면 해당 선수의 전체 기록을 볼 수 있습니다.

![선수 상세](screenshots/08-player-detail.png)

- **전체 기록** 행: 누적 합산
- **게임당 평균** 행: 경기당 평균
- 그 아래: 경기별 상세 스탯

---

## 8. 로그인 / 회원가입 (`settings`)

상단 메뉴의 **settings** 를 클릭합니다.

![로그인](screenshots/ann-06-settings.png)

1. **① 아이디**, **② 비밀번호**를 입력합니다.
2. **③ 로그인** 버튼을 클릭합니다.
3. 계정이 없으면 **④ 회원가입**을 클릭해 계정을 만듭니다. (그룹 이름을 함께 입력하면 새 그룹이 만들어집니다)

로그인하면:
- 상단 메뉴의 teams/games 잠금이 풀립니다.
- settings에서 **내 계정 정보와 소속 그룹**을 확인할 수 있습니다.
- 오른쪽 상단 **그룹 생성** 버튼으로 새 그룹을 만들 수 있습니다.

---

## 빠른 시작 체크리스트

```
□ 1. settings에서 로그인 (계정이 없으면 회원가입)
□ 2. 오른쪽 상단에서 그룹 선택
□ 3. teams에서 선수 추가 & 팀 구성
□ 4. games에서 새 게임 생성
□ 5. 경기 카드 클릭 → 실시간 기록 입력
□ 6. 경기 종료 후 rankings·daily에서 통계 확인
```

> 이 체크리스트는 그룹에 기록된 게임이 없을 때 홈 화면에도 표시됩니다.

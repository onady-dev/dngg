# DNGG(dn.gg) 마케팅·고투마켓(GTM) 전략 — 설계

- 작성일: 2026-07-19
- 대상 제품: dn.gg — 아마추어 팀 실시간 경기 기록·랭킹 앱(농구 우선)
- 상태: 방향 승인됨(A 엔진 + C 부트스트랩 + B 기반)

## 0. 전제(확정)

- **1차 목표**: 신규 그룹/유저 획득(성장).
- **주 타깃**: 사동·동호회 농구팀(정기 모임 아마추어 농구 동호회·사내 농구팀).
- **예산**: 거의 제로 → **오가닉 중심**.
- **구조적 사실**:
  - 제품은 **팀(그룹) 단위**로 채택된다. 팀당 **기록 담당(총무)** 한 명 확보 = 팀 전체 유입.
  - 경기 결과·랭킹·6각 능력치는 **공유 가능한 산출물** → 사용 자체가 광고가 될 수 있다.

## 1. 포지셔닝 & 메시지

- **카테고리**: 아마추어 팀을 위한 실시간 경기 기록·랭킹 앱(농구 우선).
- **한 줄 메시지**: "동호회 농구, 기억이 아니라 기록으로 — 기록하면 랭킹·능력치가 된다."
- **웨지**: 총무가 매번 수기/엑셀/카톡으로 득점·스탯을 정리하던 번거로움 제거 + 팀원은 자기 능력치·순위를 궁금해한다.
- **차별점**(vs 엑셀·카톡·밴드 글·기억): 실시간 터치 기록 → 자동 집계·랭킹·6각 능력치·원터치 공유.
- **메시지 앵글**:
  - 총무향: "경기 끝나고 스탯 정리 그만 — 터치 몇 번이면 랭킹·능력치가 자동으로."
  - 팀원향: "내 6각 능력치, 우리 팀에서 난 몇 위?"

## 2. 핵심 성장 루프(엔진 = 접근법 A)

```
경기 종료
  → 총무가 결과/랭킹/능력치 카드를 팀 단톡·밴드·인스타에 공유
    (카드에 dn.gg 워터마크 + 딥링크)
  → 팀원이 자기 스탯 보러 유입·정착
  → 같은 카페/리그의 다른 팀 총무가 "우리도" → 신규 그룹 생성
  → (반복)
```

이 루프가 해자다. 다른 모든 활동은 이 루프에 트래픽·팀을 먹이는 역할.

**루프 증폭 제품 지렛대**(작은 개발):
1. **공유 카드 이미지 자동 생성 + 워터마크/URL** — 능력치 레이더는 이미 구현됨 → 이미지 카드화(결과 요약/데일리 MVP/능력치).
2. **그룹 초대 링크** — 총무가 팀원을 초대 → 팀 정착률↑, 초대 수락이 곧 획득.
3. **월간/시즌 결산 카드** — 리텐션 + 공유 유발을 동시에.

## 3. 단계 계획

### Phase 0 (약 2주) — 제품 지렛대 & 계측 (선행)
- 공유 카드 + 워터마크/딥링크, 그룹 초대 링크, 랜딩페이지(가치 1줄 + 스크린샷 + CTA), 온보딩 정리.
- 이벤트 계측: 가입, 그룹 생성, 공유 클릭, 초대 수락(UTM 딥링크 포함).
- **선행조건: SES 프로덕션 승인.** 현재 미승인 상태 — 대량 유입 시 가입 인증 메일 실발송이 깨져 온보딩이 붕괴한다. 마케팅 시작 전 반드시 해결(승인 지연 시 Resend/Postmark 등 대체 발송 전환).

### Phase 1 (4~6주) — 부트스트랩 (접근법 C: 창업자 직접)
- 타깃 리스트업: 네이버 카페(지역 농구 동호회·농구 커뮤니티), 밴드 동호회, 카카오 오픈채팅("농구"/지역 픽업게임), 지역 리그.
- 총무에게 1:1 제안(무료 + 셋업 도움 + 피드백 요청). 고접촉·고전환.
- 목표: **활성 팀 20~30개** 확보(레퍼런스 + 초기 피드백).

### Phase 2 (지속) — 엔진 가동 (접근법 A)
- 공유 루프 최적화(공유 마찰 최소화, 카드 매력도 개선).
- 커뮤니티 유기적 시딩: "이번 주 우리 팀 랭킹" 같은 실제 가치 콘텐츠(스팸 아님, 카페 규칙 준수).
- 총무 앰배서더: 레퍼럴 인정/보상 = 프리미엄 기간 제공.
- 인스타그램 계정: 경기 결과·능력치 카드 리그램.

### Phase 3 (병행/장기) — 기반 (접근법 B: SEO/콘텐츠)
- 키워드: "농구 동호회 경기 기록", "농구 스탯 계산", "동호회 운영/총무" 등.
- 사용 사례 블로그, 지역 리그·대회 주최자 제휴.

## 4. 채널 우선순위 (한국 아마추어 농구 실제 서식지)

1. 네이버 카페(지역 농구 동호회·농구 커뮤니티) — 최우선
2. 밴드(BAND) — 동호회 운영 채널, 총무 밀집
3. 카카오 오픈채팅("농구"·지역 픽업게임)
4. 인스타그램(공유 카드·스토리 리그램)
5. 지역 리그/대회 주최자 제휴
6. (유튜브·블로그 = SEO 레이어, Phase 3)

## 5. 지표(깔때기)

- **획득**: 신규 그룹 수, 초대 링크 클릭→가입 전환율.
- **루프**: 경기당 공유 수, 공유→가입 전환(K-factor 근사), 팀 정착률(그룹당 활성 선수 수).
- **90일 예시 목표**: 활성 그룹 50개, 공유 유발 신규 가입 비중 30%+.
- **계측 전제**: 프론트 이벤트(공유 클릭·초대 수락) + UTM 딥링크(Phase 0에서 구축).

## 6. 리스크 & 제약

- **공유 카드 이미지 생성은 개발 필요**(현재 SSR/클라 렌더) — 최우선 지렛대, Phase 0 범위.
- **커뮤니티 시딩 스팸 오해** — 실제 가치 콘텐츠 형태로, 카페/밴드 규칙 준수.
- **창업자 시간이 병목**(제로 예산) — Phase 1 아웃리치 시간 배분을 명시적으로.
- **SES 미승인 = 마케팅 선행조건** — 미해결 시 유입이 온보딩에서 새어나감.

## 7. 범위 밖(YAGNI)

- 유료 광고(퍼포먼스 마케팅) — 예산 제로 전제상 제외. 오가닉 검증 후 재검토.
- 타 종목(풋살·배구) 확장 — 농구에서 루프 검증 후 논의.
- 앱스토어 정식 네이티브 앱 마케팅 — 현재 웹 기준. 별도 과제.

# 마케팅 Phase 0 — 실행 체크리스트 (제품 지렛대 + 계측 + 선행조건)

전략: `docs/superpowers/specs/2026-07-19-marketing-gtm-design.md`
목표: 성장 루프를 켜기 위한 최소 제품 지렛대·계측·온보딩을 갖추고, 마케팅 선행조건(SES)을 해결한다. 기간 약 2주.

## A. 선행조건 — SES 실발송 (없으면 유입이 온보딩에서 붕괴)

- [ ] `aws sesv2 get-account`로 승인 확인. 승인 시: 실제 이메일로 가입 인증 + 비밀번호 재설정 전체 플로우 실발송 스모크.
- [ ] 승인 지연/재거절 시: 대체 발송(Resend/Postmark 등) 전환 검토 — `backend/src/modules/mail/mail.service.ts` 구현 교체 + 도메인 DKIM 등록.
- [ ] 발송 실패율/바운스 모니터링 지점 확인(대량 유입 대비).

## B. 공유 카드 이미지 (루프의 핵심 지렛대)

- [ ] 공유 대상 정의: ① 선수 6각 능력치 카드 ② 경기 결과 요약 ③ 데일리/주간 MVP·랭킹.
- [ ] 카드 이미지 생성 방식 결정: 클라이언트 캔버스(html-to-image류) vs 서버 OG 이미지 렌더. (의존성/성능 트레이드오프 — 별도 설계 필요.)
- [ ] 카드에 `dn.gg` 워터마크 + 딥링크 URL(해당 그룹/선수 or 랜딩) 삽입.
- [ ] 공유 버튼: 이미지 저장 + (가능하면) 카카오 공유. 선수 상세/데일리/랭킹 화면에 배치.
- [ ] 공유 클릭 이벤트 계측.

## C. 그룹 초대 링크 (팀 정착 + 획득)

- [ ] 초대 링크/토큰 생성 API + 링크로 그룹 참여 플로우.
- [ ] 초대 수락 → 가입/그룹 참여 전환 계측.
- [ ] 총무 화면에 "팀원 초대" 진입점 노출.

## D. 랜딩페이지

- [ ] 가치 1줄 + 스크린샷(능력치 레이더·랭킹·실시간 기록) + CTA("무료로 시작").
- [ ] UTM 파라미터 수신·보존(딥링크 → 가입까지 소스 추적).
- [ ] 모바일 우선(타깃이 경기장에서 폰으로 접근).

## E. 계측(깔때기)

- [ ] 이벤트 정의·구현: `signup`, `group_created`, `share_click`, `invite_accepted`.
- [ ] UTM 딥링크로 채널별 유입→가입 전환 추적.
- [ ] 주간 확인 대시보드/시트: 신규 그룹 수, 공유 수, 공유→가입 전환, 그룹당 활성 선수.

## F. 온보딩 정리

- [ ] 신규 총무: 첫 그룹 생성 → 선수 추가 → 첫 경기 기록까지의 마찰 점검·축소.
- [ ] 첫 경기 직후 "결과 카드 공유하기"를 자연스럽게 유도(루프 진입점).

## G. Phase 1 준비(부트스트랩 사전 작업)

- [ ] 타깃 리스트 시트: 네이버 카페(지역 농구 동호회)·밴드 동호회·카카오 오픈채팅·지역 리그, 운영자/총무 연락 경로.
- [ ] 총무 1:1 제안 메시지 템플릿(무료·셋업 도움·피드백 요청) 초안.
- [ ] 레퍼런스로 쓸 데모 그룹(샘플 기록·랭킹·능력치) 준비.

## 완료 기준(Phase 0 → Phase 1 게이트)

- SES 실발송 정상(또는 대체 발송 전환 완료).
- 공유 카드(최소 능력치 or 결과 1종)와 초대 링크가 운영에서 동작.
- 4개 핵심 이벤트 계측 수집 시작.
- 랜딩페이지 라이브 + UTM 추적.
- Phase 1 타깃 리스트·제안 템플릿 준비.

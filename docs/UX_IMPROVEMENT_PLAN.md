## 1. 현재 상태 진단 요약

### 서비스 구조
- 홈(`/`) 경기 요약 → 게임 관리(`/games`) → 팀 관리(`/teams`) → 실시간 기록(`/record/[id]`) → 통계(`/daily`, `/rankings`, `/player/[id]`) → 인증(`/settings`)
- teams/games 메뉴는 **로그인 + 본인 그룹 선택 시에만** 헤더에 노출 (Header.tsx:51-64)
- 팀 구성은 서버가 아닌 **localStorage 기반** (기기 간 공유 안 됨)

## 2. UX 개선 계획 (우선순위별)

### Phase 1 — 신뢰 회복: 피드백·오류 표면화 (효과 크고 위험 낮음)

1. **토스트 시스템 도입** — `alert()` 15곳 → 토스트로 교체, `console.error`로만 끝나는 실패 20여 곳에 사용자 노출 에러 추가
2. **확인 다이얼로그 컴포넌트** — `confirm()` 5곳(게임 종료/삭제/재개, 선수 삭제, 팀 초기화) → 커스텀 다이얼로그 (파괴적 동작은 빨간 버튼 + 대상 이름 표기)
3. **버그 수정 묶음**
   - PWA 아이콘 404 (public에 icon-192x192.png 추가 또는 manifest 수정)
   - `/daily` hydration 오류(#418/#423) — 날짜 포맷의 서버/클라 불일치 추정
   - layout.tsx `metadatas` 오타 → `metadata` (단, "use client" 레이아웃이라 구조 정리 필요)
   - Login.tsx 네트워크 오류 시 `error.response.status` 접근 크래시
4. **비로그인 게이팅** — 로그인 필요 버튼은 숨기거나 비활성화 + "로그인이 필요합니다" 안내, 클릭 시 /settings 유도

### Phase 2 — 온보딩·내비게이션 (사용법 전달의 핵심)

5. **빈 상태를 행동 유도형으로 전환** (각 화면의 다음 단계 CTA)
   - 그룹 미선택: "그룹 선택" + 로그인 안내 + "처음이신가요? 가이드 보기"
   - 팀 없음(games 모달 포함): "먼저 팀을 만드세요 → 팀 관리로 이동" 버튼
   - 선수 없음(teams): "선수 추가" 버튼을 빈 상태 중앙에
6. **첫 사용 체크리스트 위젯** — 매뉴얼의 "빠른 시작 체크리스트"(로그인→그룹→팀→게임→기록)를 홈 화면 인앱 카드로: 완료 단계 체크 표시, 각 단계가 해당 화면으로 바로 연결
7. **메뉴 노출 규칙 정리** — teams/games를 항상 표시하되 비로그인 시 자물쇠 아이콘 + 클릭 시 로그인 유도 (숨김 → 잠김으로 전환해 발견 가능성 확보)
8. **모바일 헤더 개선** — 아이콘+짧은 라벨(또는 하단 탭바 전환), 그룹 선택 잘림 수정
9. **진행중 게임 방치 방지** — 홈에 진행중 게임 배너("진행중 경기 3건 — 이어서 기록하기 / 종료하기"), 오래된 진행중 게임에 날짜 경과 표시

### Phase 3 — 기록 화면(핵심 UX) 개선

10. **Optimistic update** — 기록 입력 시 전체 재조회 대신 로컬 즉시 반영 + 백그라운드 동기화 (경기 중 반응속도가 곧 서비스 품질)
11. **파울 배지 개선** — 0일 때 빨간 배지 숨김, 파울 누적 시에만 표시
12. **세로 모드 지원 검토** — 최소한 "가로 권장" 배너로 완화하고 세로 레이아웃(팀 상하 배치) 제공
13. **undo 버튼 라벨/토스트** — "방금 기록 취소됨: 준형 2점" 식 피드백, redo 버튼 복구 여부 결정
14. **선수 길게 누르기 제스처 노출** — 선수 카드에 ⋯ 메뉴 버튼 추가(길게 누르기는 보조 수단으로 유지)

### Phase 4 — 일관성·접근성·기반 정리

15. 스타일링 3종(styled-components/Tailwind/inline) → styled-components로 통일, 공용 Modal/EmptyState/Spinner 컴포넌트 추출
16. 로그인/회원가입 폼 한국어화
17. settings 확장: 내 계정·소속 그룹 표시, 그룹 생성 UI 복구(현재 주석 처리됨)
18. 접근성 기본: 모달 role/focus trap/ESC, 아이콘 버튼 aria-label, `user-scalable=no` 제거
19. 팀 구성 localStorage → 서버 저장 검토 (기기 간 공유, 총무 교체 시 데이터 유실 방지)

## 3. 사용법 전달(매뉴얼/가이드) 계획

현재: 정적 매뉴얼(`/manual/index.html`)은 잘 만들어져 있으나 ① 앱 실제 동작과 불일치(P14), ② 앱 밖에 있어 필요한 순간에 못 봄.

1. **매뉴얼 현행화** — 로그인 시 teams/games 메뉴가 나타난다는 사실 반영, 스크린샷 갱신, "URL 직접 입력" 서술 제거
2. **컨텍스트 도움말** — 각 화면 제목 옆 `?` 버튼 → 매뉴얼의 해당 섹션 앵커로 연결 (예: record 화면 → 기록 입력 순서)
3. **첫 방문 코치마크** — record 화면 최초 진입 시 1회성 오버레이: "① 선수를 누르고 ② 기록 항목을 선택하세요" (localStorage로 재노출 억제 — InstallPrompt에 이미 같은 패턴 있음)
4. **온보딩 체크리스트(Phase 2-6)와 매뉴얼 연동** — 각 단계에 "자세히 보기" 링크
5. **매뉴얼 진입점 강화** — 그룹 미선택 첫 화면에 "사용 가이드 보기" 버튼 (현재는 헤더 구석 manual 링크뿐)
